# Abdullah Hridoy Portfolio

## Deploy on Vercel
1. Extract this ZIP file.
2. Go to https://vercel.com/new and sign in.
3. Choose **Import Third-Party Git Repository** or drag/upload this folder through a GitHub repository.
4. Framework preset: **Other**. No build command is required.
5. Set Output Directory to `.` and click **Deploy**.

## Deploy on Netlify
Drag the extracted folder onto https://app.netlify.com/drop

## Files
- index.html: website
- style.css: styling
- script.js: mobile navigation
- Abdullah_Hridoy_CV.pdf: downloadable CV
